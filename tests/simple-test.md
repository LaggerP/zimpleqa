# Test: Verificar página de ejemplo

## Descripción
Este test verifica que la página de ejemplo se cargue correctamente.

## URL de prueba
https://example.com

## Pasos de prueba

1. Navegar a https://example.com
2. Verificar que el título de la página contiene "Example"

## Resultados esperados
- La página se carga correctamente
- El título contiene "Example"
